# Автозаметки 1.1 для SillyTavern

## Установка и обновление

Распакуй архив. Скопируй папку `SillyTavern-AutoNotes` в
`data/default-user/extensions/` внутри SillyTavern. Если каталог пользователя
называется иначе, используй его подпапку `extensions`. При обновлении замени
файлы в существующей папке расширения и перезагрузи страницу.

Открой чат, затем раздел **Расширения → Автозаметки**. Включи заметки
для этого чата и выбери профиль дешёвой модели из **Connection Profiles**.
Если список пуст, проверь, что встроенное расширение **Connection Manager**
включено и у тебя есть сохранённый поддерживаемый профиль.

## Что настроить

- **Макс. промптов за ход** задаёт максимум отдельных запросов на написание заметок.
  Запрос на отбор идёт отдельно. По умолчанию лимит равен двум.
- **Последних постов читать** задаёт объём контекста для отбора и написания
  заметок. В счёт входят новый пост игрока и предыдущие текстовые посты.
  По умолчанию читаются два поста.
- **Общий промпт отбора** объясняет дешёвой модели, когда правило уместно.
  Модель может выбрать любое число подходящих правил или пропустить этот ход.
- В **Промптах для заметок** через **+** добавляй свои правила.
  Если подходящих правил больше лимита, высокий приоритет идёт перед обычным
  и низким. При равном приоритете побеждает промпт выше в списке.
  Промпты из версии 1.0 сохраняются с обычным приоритетом.

Пример общего промпта:

> Ищи, где уместно добавить комментарий к ситуации. Выбери правило, если в последних
> постах появился конкретный повод применить его в следующем ответе.

Пример отдельного промпта:

> Кларк обладает силами Супермена и в повседневных сценах. Если его способности
> естественно проявятся в следующем действии, предложи одну конкретную деталь,
> которая впишется в сцену и учтёт, кто может её заметить.

## Как это работает

Выбранный Connection Profile сначала получает общий промпт, заполненные
правила и последние посты. После отбора каждое правило, прошедшее по лимиту
и приоритету, получает отдельный запрос на написание заметки.

До трёх запросов для заметок выполняются параллельно. На отбор отводится до
12 секунд, на написание до 20 секунд. Если отбор завершился с ошибкой, начнётся
обычная генерация ответа. Если часть заметок готова, в запрос к персонажу
попадут готовые заметки. Их блок вставляется в конце контекста, на глубине 0.
Участники одного хода группового чата используют общие заметки для этого поста.

Профиль, промпты, приоритеты и настройки каждого чата сохраняются в
настройках пользователя на сервере SillyTavern. На телефоне и ноутбуке
открывай один и тот же сервер под одним пользователем. Если страница
на другом устройстве уже открыта, обнови её после изменения настроек.

Панель берёт текст, поверхности, рамки и акценты из CSS-переменных активной темы.

## JSON-профили (версия 1.2)

В панели **Автозаметки → Импорт и экспорт JSON** можно:

1. Вставить весь JSON в поле **JSON-профиль** или выбрать `.json` на устройстве.
2. Выбрать **Заменить промпты и применить настройки профиля** или **Добавить промпты к существующим**.
3. Нажать **Импортировать JSON**. Изменения будут сохранены **только для открытого чата**.
4. Нажать **Экспортировать текущие**, чтобы сохранить набор правил текущего чата в `.json`.

Импорт не меняет выбранный Connection Profile, не включает заметки автоматически, не затрагивает другие чаты и не редактирует сообщения ролки. Если выбрано добавление, общая инструкция отбора и числовые настройки остаются прежними. При замене они обновляются, только если присутствуют в JSON.

```json
{
  "format": "st-autonotes-preset",
  "version": 1,
  "name": "My chat preset",
  "selectorPrompt": "Select only rules relevant to the current scene.",
  "maxPrompts": 3,
  "historyCount": 5,
  "prompts": [
    {"title": "Movement", "priority": 3, "text": "Describe a meaningful movement detail when relevant."},
    {"title": "Atmosphere", "priority": 2, "text": "Suggest a subtle environmental detail."}
  ]
}
```

`priority`: 3 — высокий, 2 — обычный, 1 — низкий. `title` необязателен; можно также импортировать просто массив записей `prompts` или массив строк, который будет считаться промптами с обычным приоритетом.

Импорт проверяет правильность JSON, наличие текстов, приоритеты и размеры и не применяет частично повреждённые данные. Числовые настройки допускают значения 1–100; максимум 200 промптов в импорте. Поля ввода и список сворачиваются для удобства работы на телефоне.

**Обновление:** если Autonotes уже установлен, замени файлы в **его существующей папке**, а не устанавливай вторую копию под другим именем. После замены обнови страницу SillyTavern. Файл `Avatar_Aang_Ji_Autonotes_EN.json` — пример отдельного готового профиля, его не нужно класть в папку расширения.
