# Автозаметки 1.3.0 для SillyTavern

## Установка и обновление

Распакуй архив. Скопируй папку `SillyTavern-AutoNotes` в
`data/default-user/extensions/` внутри SillyTavern. Если каталог пользователя
называется иначе, используй его подпапку `extensions`. При обновлении замени
файлы в существующей папке расширения и перезагрузи страницу.

В нужном чате открой **Расширения → Автозаметки**, включи заметки и выбери
профиль дешёвой модели из **Connection Profiles**. Профиль нужен для
написания микроподсказок. При пустом списке проверь встроенный
**Connection Manager** и сохранённые профили.

## Частота проверки

**Проверять раз в N постов** задаётся отдельно для каждого чата. Значение 1
проверяет каждый новый текстовый пост игрока. Поставь 3, чтобы проверять
каждый третий. После изменения интервала отсчёт начинается со следующего поста
и сохраняется при перезагрузке вместе с настройками и историей. Ответы бота
и повторные генерации не приближают проверку. Между проверками Автозаметки
пропускают отбор правил и генерацию подсказок в обоих режимах.

## Как работает поиск по смыслу

1. Оставь режим **По смыслу · векторы**. Расширение использует источник
   векторов из **Vector Storage**. При настройках по умолчанию это локальный
   Transformers на сервере SillyTavern. Для русскоязычных сцен лучше подходит
   многоязычная модель векторизации.
2. У каждого правила запиши в **Когда срабатывает** конкретный повод.
   Например: «Несс заметила, как Кларк голыми руками удержал тяжёлую конструкцию,
   и теперь спрашивает, как он это сделал».
3. В **Что подсказать** запиши правило для микроподсказки.
   Например: «Кларк выясняет, кто ещё видел случившееся. Он может признать
   то, что Несс видела сама, и дать ей время задать следующий вопрос».

Когда наступает очередь проверки, расширение сверяет индекс этого чата с текущими правилами.
Новые и изменившиеся условия добавляются, устаревшие убираются, остальные
векторы используются повторно. Если меняется только поле «Что подсказать»,
вектор условия остаётся пригодным. У старых и новых правил с пустым полем
«Когда срабатывает» в индекс идёт текст самого правила. Результаты поиска по
совпадающему контексту и условиям кэшируются на время открытой страницы.

Поиск читает столько постов, сколько указано в **Последних постов читать**,
включая новый пост игрока. После **Порога совпадения** действует **Макс. промптов
за ход**. Промпты с высоким приоритетом идут перед обычными и низкими.
При одинаковом приоритете первым выбирается правило выше в списке.

Только прошедшие отбор правила уходят в выбранный Connection Profile за
микроподсказками. Заметки вставляются в конец контекста ответа, на глубине 0.
Если совпадений нет или поиск недоступен, персонаж отвечает без автозаметок.
При первой загрузке локальной модели Vector Storage поиск может занять больше
времени. Автозаметки ждут поиск до 20 секунд и генерацию заметок до 20 секунд.

Настройки эмбеддингов берутся из Vector Storage, а ключи провайдера —
из SillyTavern. Автозаметки поддерживают серверные источники, включая
Transformers, Ollama, OpenAI, OpenRouter и Google. WebLLM, KoboldCpp и
Extras в векторном режиме Автозаметок не поддерживаются. Для Ollama,
llama.cpp и vLLM нужен настроенный адрес векторного сервера.

## Прежний отбор и устройства

Если хочешь поручить отбор языковой модели, выбери **Через общий промпт**.
Ранее сохранённый **Общий промпт отбора** доступен в этом режиме.

Правила, профиль, порог и другие настройки хранятся отдельно для каждого чата
на сервере SillyTavern. На телефоне и ноутбуке открой один и тот же сервер под
одним пользователем. Если страница уже открыта, обнови её после изменений.

## Проверка подключения

Кнопка **Проверить подключение** проверяет выбранный профиль подсказок и,
в векторном режиме, источник Vector Storage. Результаты выводятся отдельно.
Проверка отправляет короткие тестовые запросы. Для векторов используется
отдельная тестовая коллекция. Посты, промпты и история чата в проверку
не попадают.

## Цветные теги

В «Промптах для заметок» нажми **+ на второй строке под лентой тегов**, введи название,
выбери цвет и нажми **Добавить**. У каждой записи нажимай на цветные кнопки в поле **Теги**, чтобы назначить
любое количество тегов. Повторное нажатие снимает выбранный тег.

Нажми цветной тег над списком, чтобы показать относящиеся к нему записи.
Счётчик в конце тега показывает число записей с этим тегом. Запись с
несколькими тегами учитывается в каждом из них. Кнопка **Все** открывает полный
список, **Без тега** показывает записи без назначенного тега. Новая запись
получает открытый сейчас тег.

Карандаш **✏️ справа от ленты** включает редактирование названий и цветов.
Стрелки **← / →** меняют порядок тегов. Крестик **×** удаляет тег после
подтверждения **Да / Нет**. Повторное нажатие карандаша завершает редактирование. После удаления тега
у записи сохраняются остальные назначенные теги. Записи без оставшихся тегов
доступны в **Без тега**. Теги и назначения сохраняются отдельно
для каждого чата на сервере SillyTavern. Фильтр управляет отображением списка.
Автоматический отбор подсказок учитывает все правила чата.


## Загрузка JSON

Кнопка **Экспорт** под **Добавить промпт** сохраняет профиль текущего чата вместе с записями, тегами и
настройками. Этот файл можно загрузить в другой чат.

Под кнопкой **Добавить промпт** нажми **Импорт**, затем **Выбрать файл**. Переключателем выбери
**Заменить** или **Добавить**. Пояснение под переключателем описывает
выбранный режим. Для запуска нажми **Импортировать**.

В режиме **Добавить** записи и их теги добавляются к текущему профилю.
Настройки текущего профиля сохраняются. Теги с одинаковым названием и цветом
объединяются. Остальные получают собственные идентификаторы.

В режиме **Заменить** профиль полностью заменяется содержимым файла.
Если в чате уже есть промпты, появится последнее подтверждение с кнопками
**Да** и **Нет**. В пустом профиле замена происходит сразу.
Файл проверяется до подтверждения. Ошибки показываются в окне импорта.

Поддерживаются экспортированный профиль, объект с массивом prompts и
необязательным массивом tags, а также массив текстовых записей. При полной
замене настройки, отсутствующие в файле, получают начальные значения.

## Что нового

При первом открытии панели после обновления появляется короткая сводка
изменений с подсказками, где найти новые функции. Кнопка **Понятно** отмечает
версию просмотренной. Эта отметка сохраняется в настройках пользователя на
сервере SillyTavern. При следующем обновлении расширение покажет новую сводку.


## Сворачиваемые разделы

Нажми заголовок «Настройки» или «Промпты для
заметок», чтобы свернуть или раскрыть раздел. Окно обновлений использует
CSS активной темы. Кнопка «Понятно» закрывает только это окно.


Все существующие промпты при открытии чата свёрнуты. Назначенные теги видны
в заголовке записи. Новая запись сразу раскрывается для заполнения.
Кнопка добавления занимает отдельный ряд. Под ней находятся две кнопки —
«Импорт» и «Экспорт».


## Отладка и перегенерации

Раздел **Отладка** показывает последнюю проверку, номера выбранных промптов
и сгенерированные подсказки. Раскрой строку промпта, чтобы прочитать его правило
и подсказку. После сборки запроса расширение проверяет наличие текстов подсказок
в контексте и показывает подтверждение либо сообщение об их отсутствии.
Это проверка собранного запроса. Доставку и ответ сервера провайдера она
не подтверждает.

Готовые подсказки сохраняются для текущего хода в настройках чата.
Свайпы и перегенерации используют их повторно без новых запросов за подсказками.
В **Настройках** можно выключить **Сохранять подсказки при перегенерации**.
Тогда при перегенерации подсказки не добавляются. Новый пост игрока
проверяется по обычному интервалу и правилам.

В разделе **Настройки** находится проверка подключения. Импорт и экспорт
расположены под **Добавить промпт**, редактирование тегов — в кнопке ✏️ справа от тегов.


## Разделы настроек

После обновления страницы все разделы свёрнуты. В «Настройках» открой
нужную группу: «Подключение», «Частота и контекст», «Отбор правил»,
«Перегенерация».

Список промптов ограничен высотой примерно на пять закрытых записей.
Прокручивай его внутри блока, чтобы перейти к остальным. Высота также
ограничена размером экрана для работы на телефоне.


Лента тегов прокручивается горизонтально без видимой полосы прокрутки:
колесом мыши на ПК или свайпом на телефоне. Кнопка ✏️ остаётся справа и включает редактирование прямо в ленте.
Кнопка **+** находится на отдельной второй строке и открывает создание тега.
